# 🧠 Memory Card Game - Retro Pixel Edition

Trò chơi lật thẻ bài 8-bit thú vị giúp ôn tập và rèn luyện kiến thức Lập trình Web & JavaScript.

## 🚀 Tính năng nổi bật
- Giao diện phong cách Pixel 8-bit hoài niệm với đồ họa và hoạt ảnh mượt mà.
- Bảng xếp hạng và tính điểm phản xạ theo thời gian thực.
- Hướng dẫn trực quan từng bước với hình ảnh minh họa chi tiết.
- Tương thích tốt trên cả máy tính, tablet và điện thoại di động.

## 🛠️ Công nghệ sử dụng
- **HTML5** & **CSS3** (Pixel font, Keyframe animations, Responsive layout)
- **Vanilla JavaScript (ES6+)**
